# Bollenveld Duffel · 6×4 m

Mobiele planner voor een bloembollenveld van 6×4 m op zandleem (Duffel, BE), westgericht met avondzon vanaf 15u.

- **Schikking** — kies tussen stroken, drifts of stinzenweide; de soortenlijst past mee aan
- **Soorten** — 11 soorten met foto (Wikipedia), plantdiepte/-afstand en afvinklijst "geplant"
- **Bestellijst** — aantallen aanpasbaar, live totaal (bollen + richtprijs), afvinken per bestelling, kopieerknop

Statische pagina zonder build: open `index.html` of zet GitHub Pages aan (Settings → Pages → main branch).
Voortgang wordt lokaal in de browser bewaard.
